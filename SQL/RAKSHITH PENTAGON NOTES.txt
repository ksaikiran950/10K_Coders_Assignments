BRANCH
------
BRANCH_ID   INT          NOT NULL PRIMARY KEY (P_BI)
BRANCH_NAME VARCHAR(20)  NOT NULL 
AREA        VARCHAR(10)  NOT NULL
PINCODE     INT          NOT NULL UNIQUE(U_PIN),CHECK(LENGTH(PINCODE)=6) (C_PIN) 

CREATE TABLE BRANCH
(
BRANCH_ID INT NOT NULL,
BRANCH_NAME VARCHAR(20) NOT NULL,
AREA VARCHAR(10) NOT NULL,
PINCODE INT NOT NULL,

PRODUCT
-------

PNAME    VARCHAR(10)   NOT NULL
PRICE    DECIMAL(10,2) NOT NULL CHECK(PRICE>0) (C_PRICE)
QUANTITY INT           NOT NULL

(

ALTER
-----
TO MODIFY STRUCTURE OF THE TABLE WE USE ALTER

1.TO ADD COLUMN FOR TABLE
-------------------------
SYNTAX

ALTER TABLE TABLE_NAME
ADD COLUMN_NAME DATATYPE NULL/NOT NULL;

EX:

ALTER TABLE STUDENT
ADD EMAIL VARCHAR(20) NOT NULL;

ALTER TABLE CUSTOMER
ADD EMAIL VARCHAR(20) NOT NULL;

2.TO ADD COLUMN AFTER PARTICULAR COLUMN
----------------------------------------
SYNTAX:

ALTER TABLE TABLE_NAME
ADD NEW_COLUMN_NAME DATATYPE AFTER COLUMN_NAME;

PERC DECIMAL(5,2)

ALTER TABLE STUDENT
ADD PERC DECIMAL(5,2) AFTER SID;

3.TO DROP COLUMN FROM A TABLE
-----------------------------

SYNTAX:

ALTER TABLE TABLE_NAME
DROP COLUMN_NAME;

EX:

ALTER TABLE CUSTOMER
DROP EMAIL;

4.TO CHANGE THE DATATYPE
------------------------

SYNTAX:

ALTER TABLE TABLE_NAME
MODIFY EXISTING_COLUMN_NAME NEW_DATATYPE;

EX:

ALTER TABLE FACULTY
MODIFY PHONE INT;

ALTER TABLE FACULTY
MODIFY FNAME CHAR(10);

5.TO CHANGE NULL/NOT NULL
-------------------------
SYNTAX:

ALTER TABLE TABLE_NAME
MODIFY EXISTING_COLUMN_NAME EXISTING_DATATYPE NULL/NOT NULL;

ALTER TABLE FACULTY
MODIFY FNAME CHAR(10) NOT NULL;

6.TO RENAME TABLE
-----------------
SYNTAX:

ALTER TABLE TABLE_NAME
RENAME NEW_TABLE_NAME;

STUDENT_DATA

EX:

7.TO RENAME COLUMN
------------------
SYNTAX:

ALTER TABLE TABLE_NAME

ALTER TABLE STUDENT_DATA
CHANGE SID ID INT NOT NULL;

PHONE_NUMBER

CHANGE PHONE PHONE_NUMBER BIGINT;

ALIASING
--------
THE PROCESS OF PROVIDING ALTERNATIVE NAME FOR A COLUMN IN RESULTANT TABLE WILL BE KNOWN AS ALIASING.

RULES TO WRITE ALIAS NAME
-------------------------

1.WITH OR WITHOUT USING AS KEYWORD WE CAN WRITE ALIAS NAME

EX:

SELECT JOB AS DESIGNATION
FROM EMP;

SELECT JOB DESIGNATION
FROM EMP;

2.WE CAN USE MULTIPLE WORDS AS A ALIAS NAME BUT WE HAVE TO PASS IT IN QUOTES OR WE HAVE TO CONNECT THE WORDS WITH HELP OF UNDER_SCORE.

EX:

SELECT SAL*12 AS 'ANNUAL SALARY'
FROM EMP;

SELECT SAL*12  ANNUAL_SALARY
FROM EMP;

DISTINCT
--------
TO AVOID DUPLICATE VALUES FROM THE RESULATANT TABLE OR TO RETREIVE UNIQUE VALUES FROM A RESULTANT TABLE WE USE DISTINCT KEYWORD.

RULES
-----
1.EITHER * OR DISTINCT KEYWORD MUST BE THE FIRST ARGUMENT IN SELECT CLAUSE

EX:

SELECT *,DISTINCT SAL
FROM EMP;

O/P--ERROR 

2.WE CAN USE MULTIPLE COLUMNS ALONG WITH DISTINCT KEYWORD, IT WILL AVOID COMBINATION OF DUPLICATE VALUES

EX:

SELECT DISTINCT SAL,DNO
FROM EMP;

AGGREGATE FUNCTION
------------------
IT IS ALSO KNOWN AS GROUP FUNCTION

TYPES OF AGGREGATE FUNCTION
---------------------------
1.MAX():TO OBTAIN MAXIMUM VALUE FROM THE COLUMN.

SYNTAX: MAX(COLUMN_NAME/EXPRESSION)

EX: SELECT MAX(SAL)
    FROM EMP;

2.MIN():TO OBTAIN MINIMUM VALUE FROM THE COLUMN.

SYNTAX: MIN(COLUMN_NAME/EXPRESSION)

EX: SELECT MIN(SAL)
    FROM EMP;

3.SUM():TO OBTAIN TOTAL VALUE FROM THE COLUMN.

SYNTAX: SUM(COLUMN_NAME/EXPRESSION)

EX: SELECT SUM(SAL)
    FROM EMP;

4.AVG():TO OBTAIN AVERAGE VALUE FROM THE COLUMN.

SYNTAX: AVG(COLUMN_NAME/EXPRESSION)

EX: SELECT AVG(SAL)
    FROM EMP;

5.COUNT():TO OBTAIN NUMBER OF VALUES PRESENT IN A COLUMN.

SYNTAX: COUNT(*/COLUMN_NAME/EXPRESSION)

NOTE: ONLY FOR COUNT(*) WE USE * AS A ARGUMENT.

EX: SELECT COUNT(SAL)
    FROM EMP;
CHARACTERISTICS OF AGGREGATE FUNCTION
-------------------------------------
1.IT TAKES N NUMBER OF INPUT BUT GENERATE SINGLE OUTPUT.
2.IT EXECUTES GROUP BY GROUP.
3.WE CANT USE NORMAL COLUMNS ALONG WITH AGGREGATE FUNCTION IN SELECT CLAUSE
4.WE CAN PASS ONLY ONE COLUMN INSIDE AGGREGATE FUNCTION.
5.WE CANT NEST AGGREGATE FUNCTIONS.
6.WE CANT USE AGGREGATE FUNCTIONS INSIDE WHERE CLAUSE.
7.IT IGNORES NULL VALUE.
**8.WE CAN USE GROUP BY EXPRESSION ALONG WITH AGGREGATE FUNCTION IN SELECT CLAUSE.

GROUP BY CLAUSE
---------------
IT IS USED TO GROUP THE RECORDS.

CHARACTERSITICS OF GROUP BY CLAUSE
----------------------------------
> IT EXECUTES AFTER FROM CLAUSE(IF THERE IS NO WHERE CLAUSE).
> WITH OR WITHOUT USING WHERE CLAUSE WE CAN USE GROUP BY CLAUSE.
> IT EXECUTES ROW BY ROW BUT AFTER THE EXECUTION IT WILL CREATE GROUP ONLY.
> ANY CLAUSE WHICH EXECUTES AFTER GROUP BY CLAUSE WILL EXECUTES GROUP BY GROUP ONLY.
> WE CAN USE MULTIPLE COLUMN INSIDE GROUP BY CLAUSE,IT WILL CREATE GROUP BASED ON 
  COMBINATION OF THE COLUMNS

GROUP BY EXPRESSION
-------------------
THE COLUMNS WHICH WE ARE PASSING INSIDE THE GROUP BY CLAUSE WILL BE CONSIDERED AS GROUP BY EXPRESSION.

ORDER OF EXECUTION
------------------
1.FROM
2.[WHERE]
3.GROUP BY
4.SELECT

ORDER BY
--------
TO ARRENGE THE RECORDS EITHER IN ASCENDING OR DESCENDING ORDER WE USE ORDER BY CLAUSE

SYNTAX:

SELECT COLUMN_NAME/EXPRESSION
FROM TABLE_NAME
ORDER BY COLUMN_NAME [ASC]/DESC;

CHARACTERISTICS OF ORDER BY CLAUSE
----------------------------------
> IT IS A LAST EXECUTABLE CLAUSE.
> IT EXECUTES AFTER SELECT CLAUSE.
> BY DEFAULT IT WILL CONSIDER ASCENDING ORDER FOR THE COLUMNS.
> ALL THE RECORDS IN A TABLE ARRENGED IN ASCENDING ORDER BASED ON PRIMARY KEY COLUMN.
> WE CAN USE ALIAS NAME INSIDE ORDER BY CLAUSE.
> WE CAN USE MULTIPLE COLUMN INSIDE ORDER BY CLAUSE.

CHARACTER FUNCTION
------------------

> IT EXECUTES ROW BY ROW.
> WE CAN NEST CHARACTER FUNCTION.
> WE CAN USE CHARACTER FUNCTION INSIDE WHERE CLAUSE.

TYPES OF CHARACTER FUNCTION
---------------------------

1.UPPER():
----------
TO CONVERT GIVEN STRING VALUE INTO UPPERCASE WE USE UPPER FUNCTION.
 
ex: SELECT UPPER('pentagon'); O/P : PENTAGON

2.LOWER():
----------
TO CONVERT GIVEN STRING VALUE INTO LOWERCASE WE USE LOWER FUNCTION.

EX: SELECT LOWER('PENTAGON'); O/P : pentagon

----------
TO OBTAIN LENGTH OF THE GIVEN STRING WE USE LENGTH FUNCTION.

EX: SELECT LENGTH('PENTAGON'); O/P :8

4.REVERSE()
-----------
TO REVERSE THE GIVEN STRING VALUE WE USE REVERSE FUNCTION

OR

TO PRINT THE STRING VALUE IN REVERSE FORMAT WE USE REVERSE FUNCTION.

EX:
    SELECT REVERSE('PENTAGON');  O/P : NOGATNEP

SELECT CONCAT('STR_1','STR_2',.......'STR_N');

DRAWBACK
--------

JOINS
-----
IT IS USED TO RETRIEVE THE DATA FROM MULTIPLE TABLE SIMULTANEOUSLY.

TYPE OF JOINS
-------------
1.CARTESIAN JOIN/CROSS JOIN
2.INNER JOIN
3.OUTER JOIN---i. LEFT OUTER JOIN/LEFT JOIN
               ii.RIGHT OUTER JOIN/RIGHT JOIN
4.NATURAL JOIN
5.SELF JOIN 

1.CROSS JOIN
------------
TO MERGE THE RECORDS FROM ONE TABLE WITH RECORDS OF ANOTHER TABLE WE USE CROSS JOIN.

ANSI:AMERICAN NATIONAL STANDARD INSTITUTE

SYNTAX:

SELECT COLUMN_NAME/EXPRESSION
FROM TABLE_NAME  T1 CROSS JOIN TABLE_NAME T2;

INNER JOIN
----------
TO OBTAIN MATCHED RECORDS FROM TWO DIFFERENT TABLE WE USE INNER JOIN.

SYNTAX:

SELECT COLUMN_NAME/EXPRESSION
FROM TABLE_NAME T1 INNER JOIN TABLE_NAME T2
ON <JOIN_CONDTION>;

ON:IT IS A KEYWORD USED TO WRITE JOIN_CONDITION.

JOIN_CONDTION:IT IS A CONDTION USED TO JOIN MULTIPLE TABLES.

JOIN_CONDITION: T1.COLUMN_NAME=T2.COLUMN_NAME

RANKING FUNCTION
----------------
1.ROW_NUMBER()
2.RANK()
3.DENSE_RANK()

ROW_NUMBER()
------------
TO ASSIGN UNIQUE RANK FOR EACH RECORD WE USE ROW_NUMBER().

SYNTAX:
-------

SELECT ROW_NUMBER() OVER([PARTITION BY COLUMN_NAME] ORDER BY COLUMN_NAME ASC/DESC)
FROM TABLE_NAME;

OVER:IT IS USED TO PASS RANKING FUNCTION INSDIE SELECT CLAUSE.

PARTITION BY:IT IS USED TO CREATE THE GROUP AND IT WILL RESETS RANK AFTER EACH GROUP.

SELECT FNAME,DNO,SAL,ROW_NUMBER() OVER(PARTITION BY DNO ORDER BY SAL DESC) AS 'RANK'
FROM EMP;


SELECT FNAME,DNO,SAL,ROW_NUMBER() OVER(ORDER BY SAL DESC) AS 'RANK'
FROM EMP;

DRAWBACK
--------
IT WILL ASSIGN DIFFERENT RANK FOR TIED RECORDS.

RANK()
------
IT IS USED ASSIGN RANK FOR EACH RECORD ALSO IT ASSIGNS SAME RANK FOR TIED RECORDS.

SYNTAX:
-------

SELECT RANK() OVER([PARTITION BY COLUMN_NAME] ORDER BY COLUMN_NAME ASC/DESC)
FROM TABLE_NAME;

SELECT FNAME,DNO,SAL,RANK() OVER(ORDER BY SAL DESC) AS 'RANK'
FROM EMP;

DRAWBACK
--------
IT WILL ASSIGN SAME RANK FOR TIED RECORDS BUT IT SKIPS NEXT RANKING NUMBER.

DENSE_RANK()
-----------
IT IS USED TO ASSIGN RANK FOR EACH RECORD,IT ASSIGN SAME RANK FOR TIED RECORDS ALSO IT REMAINS NEXT RANK SEQUENTIAL.

SYNTAX:

SELECT DENSE_RANK() OVER([PARTITION BY COLUMN_NAME]ORDER BY COLUMN_NAME ASC/DESC)
FROM TABLE_NAME;


SELECT FNAME,DNO,SAL,DENSE_RANK() OVER(ORDER BY SAL DESC) AS 'RANK'
FROM EMP;
